# 저장소 정리 결과

전체 파일 목록 1,408개를 순회하고 잘못 놓인 임시 폴더 두 개와 빈 파일 하나를
로컬 보관함으로 이동했다. 검증된 최신 웹앱 후보 42개 파일을 백업 후 반영했다.
원본 업무 자료와 캐시는 삭제하지 않았다. 결과와 복구 위치는
[최신 인계](handoff/2026-09-27/README.md)에 기록한다. 아래 내용은 9월 20일 기록이다.

기준일: 2026-09-20. 전체 파일 목록과 크기를 조사했다. 코드 전체의 의미를 감사하거나
모든 과거 버전의 불필요함을 증명한 결과는 아니다.

- AGENTS.md에서 반복된 Agoda 규칙, 오래된 세션 환경 보장, Antigravity 설정 예시,
  중복된 도구 설정 안내를 제거했다. 도구는 실제 호출로 확인한다는 원칙은 남겼다.
- AGENTS.md는 20,428바이트에서 13,712바이트로 줄었다.
- 여행 권위, 사용자 결정, 브라우저 제한, 업무 규칙은 유지했다.
- pytest 캐시를 gitignore에 추가했다.

## 삭제 후보와 실행 결과

- 추적되지 않은 Python·pytest 캐시 575개, 14,478,850바이트를 분류했다.
- fix_r55.py, fix_r57.py, migrate_safe.py는 실행 시 코드를 문자열 치환하는 일회성
  수정 도구다. 현재 실행 코드와 일반 문서의 참조가 없고 기존 미커밋 수정도 없었다.
- 경로가 저장소 내부인지와 링크 여부를 확인한 뒤 578개 파일 삭제를 요청했지만
  자동 실행 정책이 명령을 거부했다. 실제 삭제는 수행하지 않았다.
- 목록은 cleanup-20260920.json에 있다. 삭제 완료 목록으로 해석하지 않는다.
- 원래 AGENTS.md와 수정 스크립트 3개의 백업은 해당 JSON의 backup 경로에 있다.
