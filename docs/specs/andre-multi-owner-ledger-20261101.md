## 계약

1. 담당자는 `aslan`, `andre`로 구분하며 안드레의 이름은 김동언, 별칭은 안드레다. 담당자 이름으로 카드 전체를 일괄 여행 배정하지 않는다.
2. 기존 `main`·`archive` 원본과 아슬란 여행 키는 호환 유지한다. 새 원본은 `andre_main`, 여행 키는 `andre::연도::원본 탭명`이다. 비공개 행은 원본 ID와 실제 탭명으로 조회한다.
3. 동명/동일 일정도 다른 담당자이면 다른 여행이다. 기간의 다음 여행 추론도 담당자·연도 안에서만 수행한다. 수동 여행/종료일/정본 선택/권한은 유지한다.
4. 안드레 보관 장부는 제공되지 않았다. 아슬란 보관 장부를 근거로 안드레 여행을 마감하지 않는다.
5. Google 최종 장부 쓰기는 금지한다. 수입·이체는 읽기 전용, 지출은 검토 후 사용자가 붙여넣는다. 데이터베이스 스키마 마이그레이션과 카드 재분류는 범위에 없다.
6. 원본 문서명은 `(주) 숲길따라 감성여행_안드레`다. 최초 3개 여행 확인 뒤 작업 중 재조회에서 `1105_용인`, `1111_철원`이 추가된 총 5개(`1022_홍천`, `1031_양평`, `1105_용인`, `1107_강화`, `1111_철원`)와 공식 양식 `매출자료 양식_rev`를 확인했다. 새 탭도 정기 읽기로 가져오며 마감 완료를 추정하지 않는다.
7. 이미 승인된 아슬란의 기준연도 템플릿 rollover를 보존한다. 명시된 차년도는 다시 더하지 않으며, `0206_하쿠산`·`0302_야쿠시마`의 기존 2027년 해석을 유지한다. 실제 Google 원문을 바꾸지 않는다.
