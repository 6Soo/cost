## 문서 정리/유지 규칙

1. 주제별 기존 **정본은 보존**한다. 동일 계약을 새 명세에 복사하지 말고 정본을 링크한다. 기존 상세 검증 자료/개별 사건 기록은 삭제하지 않는다.
2. 새 기능은 구현 PR에서 명세의 상태를 업데이트한다. 별도 배포 증거가 없으면 `병합 완료 / 운영 미확인`으로 구분한다.
3. 배포 후에는 인계 맨 위에 실행 SHA, 인증 화면/브라우저 수락 범위, 원본·보호표 불변, 남은 일을 짧게 기록한다. 문서 전용 병합을 이유로 재배포하지 않는다.
4. 이전 상태 문장과 최신 사실이 충돌하면 과거 문장 자체를 지우지 말고 **현재 상태 안내를 앞에 붙이고** 역사 항목으로 표시한다.
5. 새 개발 큐를 추정해서 만들지 않는다. 남은 전체 end-to-end/실기기/실자료 수락은 증거가 있는 부분만 완료 처리한다. 필요 시 개별 기능 명세의 완료 조건으로 관리한다.
6. 고객 원문·실명·금융 원본을 문서로 복사하지 않는다. Google Sheets 최종 장부는 읽기 전용이고, 자동분류·내부 기록·Google 기장·실제 환급은 별개의 상태다.
