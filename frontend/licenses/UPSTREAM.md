# Plush UI source

- Repository: https://github.com/dominikmartn/plush-ui
- Imported commit: `125a22ce151b719077637da38ffe9ec06a1a08c5`
- Imported files: `components/ui/button.tsx`, `checkbox.tsx`, `switch.tsx`, `radio-group.tsx`, `tabs.tsx`, `input.tsx`, and `select.tsx`.
- The imported component files are preserved as source under `src/components/plush/`; the project supplies the COST meaning-token mapping and public wrappers around them.
- License: MIT, reproduced in `plush-ui-MIT.txt`.
- The upstream `Open Runde` font is not imported. The product uses the repository's Pretendard Variable font instead.

The source revision is fixed; no automatic update from upstream is configured. Relevant Radix, class-variance-authority, and Hugeicons versions are pinned to the imported upstream package manifest in the frontend lockfile.
