### 검사 파일 위치 이동 (영향 게이트 준수)

`tests/test_ledger_navigation_scroll.py` → `webapp/tests/test_ledger_navigation_scroll.py`로 이동(`git mv`, rename 64%로 감지). 이유: 영향 게이트(`tools/run_quality_checks.py`)는 변경된 모든 코드 경로가 `config/test-impact-map.json` 그룹에 매핑되기를 요구하는데, 이 최상위 `tests/` 파일은 어떤 그룹 패턴에도 매칭되지 않아 `UNKNOWN_IMPACT:1`로 막혔다. map은 수정 금지라, 파일을 `webapp/tests/`로 옮겨 기존 `core-safety-net` 그룹의 `webapp/*.py` 패턴에 매칭되게 했다. 이 파일은 `webapp` import만 쓰는 자기완결 검사(fixture·conftest 의존 없음)라 이동 후에도 3건 모두 통과를 확인했다. map·게이트 도구·묶음 밖 파일은 건드리지 않았다. 위 표의 `test_ledger_navigation_scroll` 3건은 새 위치의 같은 검사다.
