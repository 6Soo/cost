# 한 항목만 남은 관리 메뉴 교정 및 검토 누락 원인

현재 요청: 첨부된 사이드바 구조의 발생 원인과 `better-ui` 검토 누락 원인을 설명하고 수정한다. 기존 운영 반영 승인에 따라 검증 후 배포한다. 범위는 모든 화면이 공유하는 사이드바의 소유자 메뉴와 조회자 메뉴 보호다.

## 발생 원인

1. `4c7579d956bed2635307ec7e8d2e113a1e09346c`는 여행 관리·예약 연결·계정 관리 세 항목을 `details.nav-management` 아래에 배치했다. 항공 메뉴는 주요 메뉴로 옮겼다.
2. `e9898a03cd62f835b174f398952a8f04642b46d2`는 여행 관리와 예약 연결을 여행 화면 안으로 옮기면서 두 링크만 삭제했다. 한 항목만 남은 상위 `details`와 ‘관리’ 제목, 별도 nav의 안쪽 여백을 보존했다.
3. 결과적으로 메뉴 하나에 도달하려고 ‘관리’를 펼쳐야 했고, 펼쳤을 때도 두 메뉴 사이에 불필요한 제목과 간격이 생겼다. 개별 링크 이동만 검증하고 이동 후 메뉴 트리 전체의 유효성을 재평가하지 않은 구성 오류다.

## 이전 스킬 검토에서 놓친 이유

- 실제 `better-ui/SKILL.md`는 표면·아이콘·동작을 소유하며 구조와 그룹화는 `better-layout`의 영역이라고 명시한다. 또한 “underlying interaction is sound” 이후의 polish라는 전제가 있다. 스킬 호출만으로 정보 구조 검증이 수행되는 것은 아니다.
- 이전 `better-interface` 검토 기록은 명암·오류 복구·축소 동작·뷰포트 검사에 집중했다. 후속 `continuation-interface-review.md`는 변경 범위의 새 회귀만 검토했으며, 기존 관리 메뉴의 펼친 상태 및 한 항목 그룹의 필요성에 대한 증거는 없다. 미변경 메뉴를 새 회귀가 아니라는 이유로 통과시킨 검토가 전체 화면 진단을 대신했다.
- `webapp/tests/test_site_shell_convergence.py`는 `_nav_html`을 축약된 가짜 HTML로 교체했다. 그 메뉴에는 관리 그룹 자체가 없으므로 테마·오버플로 검사가 통과해도 실제 문제는 검사되지 않았다. 기존 `test_site_shell_browser.py`는 실제 서버를 사용하지만 해당 계정 경로의 직접 접근과 상위 계층을 검증하지 않았다.
- 따라서 원인은 스킬의 한계만이 아니라 적용과 완료 판정의 누락이다. 스크린샷이 있다는 사실과 주요 흐름을 실제로 확인했다는 사실을 구분해야 했다. 이번에는 실제 렌더러의 실패 재현을 남기고 메뉴의 계층·직접 접근·키보드 순서·선택 상태를 검사한다.

## 검토 범위와 결과

Python HTML 렌더러와 기존 CSS/JS 셸을 사용한다. 저장소 AGENTS.md, 화면 명세 `ui.md`, 기존 core-ui-reduction 및 관리자 UI 검토 기록을 대조했다. 최신 사용자 교정에 따라 관리 접기는 한 항목에 적용하지 않는다. 금융 처리·API 계약·데이터 구조는 변경 대상이 아니다.

## 검증

- `python -m pytest -q webapp/tests/test_site_shell_browser.py -k account_navigation --tb=short`: 수정 전 실제 서버 9개 조합 실패. 수정 후 1 passed, 9 subtests passed. 장부·계정·활성 항공의 320/390/1440px 조합이다. 메뉴 렌더러를 대체하지 않는다.
- 인접 셸 검사 21건과 기존 16개 하위 검사는 첫 후속 실행에서 통과했다. 새 검사에서 발견한 측정 타이밍 문제는 메뉴 애니메이션 완료를 기다리고 실제 Tab 이동 후 초점을 확인하도록 수정했다. 최종 영향 검사 결과는 운영 기록에 별도 기록한다.
- Ego TaskSpace 26: 실제 합성 서버, 항공 기능 활성 상태의 세 경로, 동일 크기 1440×900/390×844 전후 화면, 320px, Enter로 계정 화면 이동, 밝은/어두운 테마와 200% 확대 확인. 합성 자료만 캡처했다.
- 전후 화면: `quality-artifacts/admin-ui-ux/sidebar-before-desktop.png`, `sidebar-after-desktop.png`, `sidebar-before-mobile.png`, `sidebar-after-mobile.png`. 측정 JSON과 추가 캡처는 Git 제외 `.local-archive/sidebar-structure-20261105/`에 보존한다.
- 미검증: 수동 스크린리더, 물리 모바일, RTL·번역. 검토 결과는 이 공유 메뉴 흐름에 한정하며 전체 관리자 UI 무결함 판정으로 확대하지 않는다.

검토 범위에서 발견한 MEDIUM 구조 결함을 수정했고 남은 HIGH/MEDIUM 결함은 확인되지 않았다. **Approve — 위에 명시한 공유 메뉴와 검사 범위만 해당.**
