## 1. 노트북 중단 이유

- 실측 CPU 100%, 사용 가능 RAM 184MB, 커밋 메모리 93.5%.
- Agoda 단일 탭도 DOM 판독·직접 목록 진입이 30초를 넘겨 브라우저 제어가 반복 초기화됐다.
- LibreOffice Python의 도메인 전체 재적재 테스트도 장시간 CPU를 점유해 종료했다.
- 따라서 노트북에서 조사·브라우징·추가 OCR을 중단했다. 자원 포화는 데이터 오류가 아니라
  실행 환경 병목이다.
