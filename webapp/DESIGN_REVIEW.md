# 웹 장부 디자인 검토 안내

## 2026-09-27 현재 상태

아래 초기 검토는 64862ac 시점의 기록이다. 현재는 `ledger_design.py`의 A안 기반
Ramp 레이아웃과 자체 제공 Pretendard를 실제 화면에 연결했다. PC 우측 편집 패널,
모바일 거래 목록, 규칙 대화와 합성 공급자 전환도 포함한다. 실제 AI 연결과 인증은 미완료다.
최신 검증과 재개 범위는 [현재 인계](../docs/handoff/2026-09-27/README.md)를 우선한다.

## 먼저 읽을 파일

- [실행 안내](README.md)
- `ledger_board.py`: HTML, CSS, 화면 및 HTTP 경로
- `ledger_store.py`: 저장, 여행 관리, 배분, 수정과 되돌리기
- `card_import.py`, `income_ledger.py`: 카드 및 은행 업로드
- `sheets_export.py`: 선택 여행 XLSX 출력
- `tests/`: 합성 자료로 검증하는 동작 계약

## 현재 구현

여행별 장부, 수입 위·지출 아래 표, 여행 검색·관리, 행 편집·저장·되돌리기, 카드 업로드와 분류대기, 직접 수입·지출, 은행 파일 업로드·정정, 입금 배분, 선택 탭의 다중 시트 XLSX 출력을 제공한다. 같은 내용의 은행 파일은 이름이 달라도 재사용한다.

검증된 후보는 전체 테스트 152개와 세부 검사 9개가 통과했다. Chromium 폭 390에서 수정·되돌리기·카드 업로드·다운로드를 확인했다. Excel PDF 출력은 3쪽에 수입·지출·수익이 포함된다. 실제 휴대폰과 물리 프린터는 미검증이다.

## 디자인 검토 목표

스프레드시트의 정보 밀도와 토스의 명확한 정보 우선순위를 함께 참고한다. PC는 좌측 여행 탭, 본문 수입 위·지출 아래를 유지한다. 장식용 차트와 과도한 카드·여백을 피하고 숫자 비교와 행 편집을 쉽게 만든다. 현재 화면은 기능 검증용이며 최종 디자인이 아니다.

모바일은 모든 정보와 편집 기능을 유지하되 표를 단순 축소하지 않는다. 업로드 진행, 분류대기 이동, 오류 복구, 행 저장 상태, 선택 여행 출력 흐름을 우선 검토한다.

## 계획과 구현을 구분할 것

AI 규칙 대화와 Muse/Gemini 전환, Google 로그인, 직원 담당 여행 조회 권한, 예약 시스템 연동, 운영 자료 이관 및 배포는 앞으로 구현할 범위다. 현재 구현된 기능처럼 설명하지 않는다. 직원 조회·포트폴리오 예시 공개는 목표이며 현재 서버는 로컬 합성 데모다.

## ChatGPT 검토 요청

위 코드와 테스트를 근거로 현재 화면과 기능을 파악한 뒤 실제 제품 사례를 찾아 디자인 방향을 제안한다. 구현된 기능과 계획 기능을 분리하고, 기능 누락 없이 PC·모바일 와이어프레임을 제시한다. 저장소를 읽는 것과 실행 화면을 보는 것은 다르므로 실제 실행하지 않은 화면은 추정이라고 명시한다.
