수기 원본은 읽기 전용이며 동일 거래의 항목·메모 차이는 표시한다. 같은 행의 이중 점유, 복수 후보, 원본 충돌, 검증되지 않은 시트는 신규 복사에서 제외한다. 연결만 저장하는 것은 Google 기록 완료가 아니다. 내부 장부 기록도 Google 입력 여부와 별개다.

수입·은행 이체는 사용자가 Google에 직접 입력하고 COST는 읽는다. 지출은 COST에서 검토·복사해 사용자가 붙여넣는다. **Google 최종 장부 자동 쓰기는 금지**한다. 운영 수락 과정의 실제 분류·여행 배정·환불·수기 연결 메타데이터 저장은 실행하지 않았다.
