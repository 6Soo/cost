# 보험·수입 대조 영역 UIUX 개선 — 2026-11-01

## 사용자 요청과 범위

사용자는 전체 보험·수입 대조 영역의 UIUX 개선, 수입에 연결된 참가자의 목록 제외, 수입 행 대조 버튼 삭제를 요청했다. 추가 확인에서 범위는 COST 사이트 전체가 아닌 첨부한 보험·수입 대조 영역 전체로 확정했다.

## 구현과 수락 기준

| 요청 | 구현 | 검증 |
| --- | --- | --- |
| 영역 전체 UIUX | 제목 중복 제거, 요약 세 항목, 검색·초기화·원본/전체관리 도구, 미연결 참가자 목록, 하나의 연결 입력, 모바일 배치·테마·44px 조작 영역 | 합성 PC1440/모바일320·390/가로844, 밝은/어두운 테마·동작 줄이기·빈 검색·자료 없음·전체 연결·연결 확인 취소 |
| 연결된 참가자 목록 제외 | 실제 연결 ID로 목록을 먼저 거른 다음 페이지 분할. 전체 미연결 참가자는 선택 가능하며 수입 표의 연결 상태·개별 해제와 별도 전체 관리는 유지 | 연결21명/총31명 사례의 목록31→10명, 링크/원본 불변, 뒤쪽 참가자 누락·이전 페이지·오래된 offset 교정 |
| 수입 행 대조 버튼 삭제 | 초기 HTML·동적 갱신·오류 재시도에서 수입 행 대조 버튼 제거. 아래 영역의 한 입력으로 연결 | 실제 운영 수입35행, 행 대조 버튼0, 연결 입력1; 기존 드래그·확인·해제·권한·CSRF·fingerprint 보호 |

참가자 목록의 표시는 업무 대상만 좁힌다. 기존 연결을 삭제하지 않으며, 다대다 연결의 업무 의미를 변경하지 않는다. 연결된 참가자의 추가 연결·관리는 기존 전체 연결 관리에서 가능하다. Google 최종 장부 자동 쓰기 금지를 유지한다.
