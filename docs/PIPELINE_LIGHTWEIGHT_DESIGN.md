# 비용 파이프라인 경량화 설계안

## 목적
같은 원천과 판정을 여러 단계에서 반복하지 않되, 비용 누락·증폭·중복과 잘못된 권위 승격은 막는다.

## 유지할 규칙
- 결제일로 여행을 만들지 않는다.
- 권위 일정은 연도·시작일·종료일·종료 의미·권위 종류·authoritative 상태·source_sha256를 모두 확인한다.
- 후보와 보류를 확정하지 않는다. 음수·0원 구매를 양수로 바꾸지 않는다.
- 기존 자료와 산출물을 덮어쓰지 않는다. 외부 전기는 별도 확인한다.

## 경량 구조
1. 실행 준비: 봉인된 원천을 실행당 한 번 직접 해시해 `source-manifest.json`을 만든다. 저장된 manifest만 믿지 않는다.
2. 기존 정규화 재사용: 새 정규화 엔진과 새 식별자를 만들지 않고 `direct_sources.py`, `direct_projection.py`의 결과를 재사용한다.
3. 관계와 일정 판정: 권위 일정 로드와 관계 판정을 실행당 한 번 수행하고 행별 근거를 저장한다.
4. 얇은 투영: 후보, 초안, shadow, 워크북은 공통 판정 결과만 읽고 자기 출력 형식만 검사한다.
5. 감사: 원천은 실행 시작 때 한 번 직접 해시하고, 산출물마다 재해시하지 않는다. `external_pending`은 통과가 아니며 `release_eligible=false`를 유지한다.

## 검사 층
- 항상: 입력 경로, 봉인 입력 해시, 필수 열, 형식, 중복 ID, 음수·0원, 권위 필드, 출력 충돌.
- 실행당 한 번: 원천 집계, 기존 정규화, 일정 로드, 관계 판정, signed total.
- release 때만: 전체 계보, 의미 해시 재계산, 외부 멱등 키 조회, 워크북 시각 검토, 운영 버전 대조.

## 재실행
입력과 의미 해시가 같으면 `verified_skip`으로 기록하고 내부 산출물을 다시 만들지 않는다. 이는 외부 전기 중복 방지를 뜻하지 않는다. 해시가 다르면 새 실행으로 분리한다.

## 수용 기준
같은 입력과 행 순서는 같은 의미 해시를 만들고, 업무 필드 변경은 해시를 바꾼다. 기존 v2 자료는 읽는다. 후보는 확정되지 않는다. 원본·운영 DB·외부 전기는 바꾸지 않는다.
