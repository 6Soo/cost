## 실제 확인과 대기 조건

- 메일: 기존 전용 Drive 읽기 전용 인증으로 manifest 한 개를 재조회했다. 메시지3,710·pending48·다음 페이지 있음·query 활성이다. `stored` 필드는 없으며 과거 `last_complete`의 존재만으로 현재 열거 완료로 볼 수 없다. 원문 다운로드·Drive 쓰기·수집기 전환은 수행하지 않았다. pending/query/다음 페이지가 소진되면 같은 경로로 다시 확인한다.
- 참가자: 기존 Aside 인증 세션의 상태 API는 HTTP200이나 `configured=false`, `complete=false`, `STORE_UNAVAILABLE`다. worker의 현재 프로세스 기본 DB 경로 확인은 운영 웹 프로세스의 실제 환경 확인과 구분한다. 실제 연결 DB와 등록 영수증 확인이 필요하다. 보험 전달 수락을 등록 영수증 일치로 대신하지 않는다.
- 금융: 기존 보관 집계는 카카오 취소39/연결29/미연결10, Agoda76/73/3, Trip186/171/15이다. 현재 금융 자료를 다시 대사한 수치가 아닌 보관 요약이다. 원결제 증거는 확인하지 못했으며 파일명 검색만으로 전체 운영 DB의 증거 부재를 증명하지 않는다. 대응 원결제 원본 또는 명시적 증거가 승인된 자료 경로에 생기면 재검토한다. 카드 수집·업로드 보류는 유지한다.
- 기기: `adb devices`에 연결 기기가 없었다. Windows 모니터·브라우저 에뮬레이션은 모바일 실기기 수락 근거가 아니다. 대상 기기의 접근 경로가 확보되면 터치·테마·확대·화면 폭 수락을 진행한다.
- 운영: 최초 worker 진단의 잘못된 포트와 스케줄러 비교는 검토에서 거부했다. 해당 실패나 ACL 문자열 추측은 운영 장애·권한 보호 근거로 쓰지 않는다. 보완된 진단의 실제 실행에서 등록·활성 task와 기대 release runner 인수는 일치했다. 실행 파일은 확장자 없는 `powershell`이며 실제 해석 경로·ACL 유효 쓰기 권한은 미검증이다. working directory 비일치만으로 장애로 보지 않는다. 감독자 제한 GET은 healthz200/259ms, readyz200/20ms였다. 실제 사용자 검색/첫 렌더/DB lock의 성능 수락으로 해석하지 않는다.

## 구현·통합 검증

- OTA: 검증된 이용기간이 부적합한 저장 추론을 대체할 수 있게 하고, 철회된 예약 배정 규칙은 활성 근거에서 제외한다. 철회 후에는 일반 카드 날짜 추론으로 같은 실제 여행을 다시 선택할 수 있으므로 목적지 자체보다 출처를 검사한다. history-recovery보다 기간 근거가 우선하며 사용자 국가 예외와 활성 수동 예약 배정은 보존한다. 합성 스냅샷 reader를 격리해 teardown 경합을 차단했다. 초기 Python3.14 크래시를 통과 근거로 세지 않는다.
- 메일: manifest에 `stored` 필드가 있으면 실제 메시지 수와 일치하는 정수인지 검사한다. 실제 원격 manifest에는 이 필드가 없었으며 pending/query/페이지 보호를 별도로 유지한다.
- UI: 추출된 공유 CSS/JS 자산과 단일 수동 테마 계약에 맞게 기존 검사 세 건을 수정했다. 제품 화면 수정이나 실기기 수락을 주장하지 않는다.
- 운영 도구: 지정된 SHA/경로와 실제 scheduler wrapper 참조를 민감한 원문 출력 없이 진단한다. loopback의 healthz/readyz만 제한 조회하고 redirect를 거부한다. 연결 오류를 HTTP 상태로 창작하지 않으며 ACL과 실행 경로 확인 수준을 명시한다. 수락 게이트 PASS 도구가 아니다.
- 참가자의 중복 진단 필드와 실제 생산 경로가 없는 금융 집계 검증기는 통합하지 않았다. 고객 자료·금융 링크·명단 등록을 임의로 만들지 않았다.
- 통합 검사: 메일·진단·테마63 passed, OTA·분류 교정·exact/manual/부분환불24 passed. UI worker의 공유 자산 포함11 passed는 별도 근거다. 전체 회귀·실기기·실금융 적용은 실행하지 않았다. 합성 결과를 운영 자료 수락으로 표시하지 않는다.
