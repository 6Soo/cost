# 거래 상태 통합과 코드/AI 추론 분리

현재 사용자 승인: 상태·사유를 단순화하고 추론을 코드 추론/AI 추론으로 나누며 실제 처리 기능도 일치시킨다.

**2026-11-05 최신 UX 결정:** P1/P2는 자동 처리 내부 단계이고 P3의 실제 인간 판단만 [통합 사용자 확인함](unified-expense-action-queue-20261105.md)에 노출한다. 사용자 보류 상태·사유·필터·해제 UI는 제거 대상이다. transaction_review_holds 등은 UI와 분리된 내부 금융 안전 잠금으로만 유지한다. 아래 과거 구현 검증표는 작성 당시의 상태/출처 검증 근거이며 새 통합 작업함이 구현됐다는 뜻은 아니다.

- 화면 상태: 처리 필요 / 완료 / 제외. 완료는 COST 내부 기록이며 Google 반영·은행 환급과 구별한다.
- 출처: 자동 / 코드 추론 / AI 추론 / 직접. 기존 inference와 auto_inferred는 코드 추론이다. 단순 코드 재검토의 P2_REVIEW 표식은 AI 실행 증거가 아니다.
- 내부 분류 사유: 분류·배정 필요 / 근거 충돌 / 결제·환불 확인. 사용자 작업은 별도 action task로 관리하며 사용자 보류를 거래 사유나 상태로 노출하지 않는다. 구체적인 내부 보호 사유·원본·수동결정·중복·환불 검증은 보존한다.
- 코드 처리를 먼저 실행한다. 남은 분류나 명시적으로 선택한 자동분류 교정은 기존 연결 에이전트가 AI로 검토할 수 있다. AI 결과는 제한된 기존 여행·항목, 원본/버전/문맥 digest와 실행 메타데이터를 검증한 뒤 원자 적용한다. 수동 답변으로 기록하지 않는다. 코드가 만든 기본값을 AI가 검토했다고 표시하지 않는다.
- AI 검토는 기존 연결 에이전트의 로컬 자료 대조 경로다. 신규 유료 모델·키·외부 고객 원문 전송·상시 서버 AI 호출은 추가하지 않는다. 읽기/preview는 DB 쓰기와 외부 호출이 없다.
- 승인된 코드 구현→표적 및 보호 검사→리뷰→정상 PR/main→고정 SHA 코드 배포와 최소 운영 smoke까지 수행한다. 금융 자료 일괄 재분류·마이그레이션은 이 코드 배포에 포함하지 않는다.

## 연결 에이전트의 실제 P2 실행

`tools/review_card_inference.py --host-root <보호호스트> --transaction <ID> --output <로컬요청.json>`은 읽기 전용 DB의 메모리 사본에서 P1을 먼저 실행하고 P2 요청을 만든다. 원문·가맹점 원문·이름·카드번호·예약번호는 요청에 포함하지 않고, 기존 비용 항목·이용일·유효 여행 기간·파생 서비스 항목만 전달한다. 이미 충분한 코드 분류는 재검토하지 않으며, 명시 선택한 자동분류 교정에만 `--reconsider`를 쓴다.

연결 에이전트는 요청의 `digest`를 `request_digest`로 돌려주고 `execution`에 `kind=connected_agent`, 실제 `provider/model/run_id`를 남긴다. `results`는 각 대상의 `transaction_id/trip_id/item/basis/uncertainty`를 포함한다. 코드를 실행했다는 이유만으로 이 결과를 만들거나 AI 검토라고 표시하지 않는다. 근거가 약해도 실제 여행의 최선 후보와 비용을 고르고 불확실성을 기록하며 사용자 답변을 창작하지 않는다.

동일 명령에 `--request <로컬요청.json> --response <AI결과.json> --output <별도미리보기.json>`을 추가하면 사본에서 P1→P2 전체 경로를 검증한다. 실제 적용은 기존 백업/별도복원·단일 작성자 게이트, `--apply --expected-digest <미리보기digest> --backup-evidence <보호호스트증거.json>`를 요구한다. AI 귀속/출처/감사와 기존 내부 기록 작업 큐를 한 트랜잭션에 저장하고, 내부기록은 기존 작업자가 재개한다. 새 금융 연결·Google 쓰기·스키마 변경은 하지 않는다. 재실행은 적용0이며 요청/결과 파일을 덮어쓰지 않는다.

기존 검사의 실패6건은 시작 SHA `6302e767`에서도 동일 node로 재현했다. 예전 문구·준비 가능 상태·오래된 source 문자열을 요구하는 검사이며 통과 수에 포함하지 않는다. 근거는 Git 제외 `.local-archive/status-inference-20261102/`의 `baseline-tests.xml`, `final-tests.xml`, `final-gates.xml`, `browser-synthetic.json`, 합성 agent request/response다. 전체 회귀·실기기 검사는 실행하지 않았다.
