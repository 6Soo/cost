## 초기 판단·구현 (위 개정 전 이력)

SPEC §1.5·§13, TRIP-001~003·098, GGL-012·016을 따른다. Google 제목/지출 기간의 명시 종료일은 기존 값이 있어도 갱신한다. 같은 여행 키·담당자·시작일이어야 하며 다른 연도 동명 탭과 stale 원본은 갱신하지 않는다.

보존 출처: 생성 이후 Google 이외 실행자가 바꾼 종료일, WEBLEDGER_TRIP_AUTHORITY의 authoritative 사용자 확인 일정과 비-workbook 근거(owner-schedule/reserve 등). 지정된 구성 파일이 깨지면 수입을 중단한다. 생성 actor=owner는 옛 자동 수입에서도 사용되어 실제 수동 수정으로 보지 않는다. 노리쿠라의 8/5→8/6→8/5 owner meta 이력은 보존한다. 화순의 옛 user_confirmed_schedule 2026-08-23~25만 TRIP-098의 8/26으로 대체하며 다른 기간에는 예외를 확대하지 않는다.

빈 값·추정 종료일의 기존 동작은 유지한다. save_trip_meta의 revision·이전/이후 값·google-sync 감사 경로를 재사용한다. 요청 키에 revision을 포함하여 A→B→A→B 변경이 과거 멱등 응답에 막히지 않게 한다. 재판정·원본·authority/evidence/source_sha256 변경은 하지 않는다.
