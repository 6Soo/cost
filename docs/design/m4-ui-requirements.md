## 2. LOW 목록

각 항목은 M4 컴포넌트 기본값으로 해결한다.

- 터치 대상이 작은 링크·펼침(여행 링크 22x15, 단계 링크 60x15 등): 대상 크기 최소 24x24(가능하면 44x44).
- 금액·날짜 열의 고정 폭 숫자(`tabular-nums`) 누락: 숫자 열은 고정 폭 숫자를 쓴다.
- 좁은 폭에서 내부 가로 스크롤(`section-tabs`, 표 래퍼): 스크롤 영역은 초점을 받고 스크롤됨을 알린다.
- 빈 상태 문구가 화면마다 다름: 빈 상태 컴포넌트 하나로 통일한다.
- 비활성 버튼의 이유가 보이지 않음(복사, 저장, 취소, 적용): 비활성 사유를 글로 보인다.
- 숨은 읽기 전용 캡션·상태(`sr`) 문구가 잘림 판정에 걸림: 시각적으로 숨기는 방식을 통일한다.
