- 변경 파일은 테스트와 이 대조표뿐이다. `webapp/card_flow.py`, `webapp/card_actions.py`, `config/test-impact-map.json`, `docs/session_handoff.md`는 수정하지 않았다.

- 저장·원본·금액·합계 기대값을 낮추지 않았고 skip/xfail을 추가하지 않았다.
- 변경 파일 재실행: 6개 파일, **63 passed / 24 failed / 7 subtests passed**.
- `python tools/run_quality_checks.py --base origin/main --run` (실행 SHA `f0ff43ec2f79a248ec565811fdc316a740daa045`): **277개 대상 실행, 261 passed / 24 failed / 22 subtests passed, skip 0, compile 0**. 최종 커밋의 추가 변경은 이 검증 기록 문서뿐이다.
- 같은 18개 파일을 `origin/main`에서 별도 worktree로 실행: **254 passed / 36 failed / 17 subtests passed**. 양쪽 JUnit의 `classname::name`을 비교했으며 브랜치 전용 실패는 **0건**이다. 기준선에서 실패하고 브랜치에서 통과한 이름은 9건이며, 브랜치의 남은 24개 실패는 모두 기준선에도 같은 이름으로 실패했다.
- 최초 영향 검사 호출은 작업 트리가 아직 커밋되지 않아 도구가 `NO_CHANGES`를 반환했고 검사 단계가 없었다. 커밋 후 다시 실행해 실제 결과를 기록한다.
