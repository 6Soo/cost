# 지출 정리 화면의 스크롤 중 메뉴 접근

## 승인 범위

지출 정리 화면에서 긴 목록 아래로 이동해도 여행 목록과 주요 화면 이동 메뉴에 접근한다. 금융 분류와 저장 동작은 바꾸지 않는다.

## 동작과 완료 조건

- 데스크톱에서는 왼쪽 메뉴를 화면 높이 안에 유지하고, 긴 여행 목록은 메뉴 내부에서 스크롤한다. 본문은 독립적으로 스크롤할 수 있다.
- 작은 화면에서는 메뉴 열기 버튼이 본문 스크롤 중에도 상단에 남는다. 기존 메뉴 열기, 닫기, 배경 마스크와 키보드 접근을 유지한다.
- 문서 전체 스크롤과 본문 스크롤 중 실제 사용하는 경계를 확인하고 수정한다. 단순히 sticky 속성만 추가하지 않는다.
- 상단 고정 영역이 본문과 표 헤더, 모달을 가리지 않도록 높이와 겹침 순서를 조정한다. 가로 스크롤을 새로 만들지 않는다.
- 지출 정리 외 공유 레이아웃 소비 화면도 기존 탐색 동작을 유지한다.

## 파일 소유권과 검증

- UI 작업자는 `webapp/ledger_design.py`와 새 탐색 전용 테스트 파일만 수정한다. 다른 파일 수정이 필요하면 Supervisor에게 알린다.
- `webapp/card_flow.py`, 분류 엔진, 운영 DB와 설정은 Supervisor 소유이며 수정하지 않는다.
- 긴 합성 목록으로 데스크톱과 모바일에서 아래로 스크롤한 후 메뉴 접근과 열기/닫기를 확인한다. 브라우저 작업은 Aside REPL을 사용한다.
- 변경 CSS/HTML 계약의 표적 검사만 실행한다. 전체 회귀, 배포, 서비스 재시작과 운영 데이터 변경은 하지 않는다.
- 작업자는 커밋하지 않고 실제 변경 파일, 검사 명령과 결과, 브라우저 확인 범위를 반환한다. Supervisor가 diff를 검토하고 통합한다.
