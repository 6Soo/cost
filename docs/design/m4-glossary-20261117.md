# M4 용어집 (2026-11-17)

> 수락 정본 [m4-ui-requirements.md](m4-ui-requirements.md) #12(용어 혼용)의 **용어집 한 벌**이다. 하나의 뜻에 하나의 이름을 쓴다. 대조 시험은 `frontend/tests/acceptance/glossary.test.ts`가 화면 소스를 정적 스캔해 강제한다.

## 표준 용어

| 개념(코드 키) | 표준 이름 | 쓰지 않는 말 | 근거 |
| --- | --- | --- | --- |
| 거래 항목(`item`) | **항목** | — | `api/types.ts`(item 라벨), `features/auxiliary/rules.tsx` CONDITION_LABELS |
| 거래 구분(`kind`) | **구분** | — | `api/types.ts`(kind 라벨) |
| 분류(`category`) | **분류** | — | `rules.tsx` CONDITION_LABELS, `features/admin/google.tsx` |
| 수입 구분(`income_kind`) | **수입 구분** | — | `api/types.ts` |
| 카드 구분(`card_kind`) | **카드 구분** | — | `rules.tsx` CONDITION_LABELS |
| XLSX 파일 산출·내보내기 동작 | **내보내기** | 출력 | `features/auxiliary/export.tsx`, `api/types.ts`(XLSX 내보내기·내보내기 상태·내보내기 다운로드), `features/ledger/index.tsx` |

- `item`·`kind`·`category`는 서로 다른 뜻이므로 이름을 섞지 않는다(항목≠구분≠분류). 각 키는 위 표준 이름 하나로만 라벨링한다.
- XLSX 산출은 **'내보내기'로 통일**한다. '출력'은 쓰지 않는다(장부 내보내기 안내의 '출력 작업'을 '내보내기 작업'으로 교정했다).

## 금지 문구

- **책임 전가 표현 금지**: "관리자가 설정하면", "관리자가 설정" 같은 문구를 화면에 두지 않는다. 동작 가능 여부는 서버가 광고한 권한·상태로 안내한다.
- **폐지된 화면 링크 금지**: 없는 대상 주소는 404 화면과 상태 코드를 돌려준다(#10). 폐지 링크를 남기지 않는다.

## 대조 시험

`frontend/tests/acceptance/glossary.test.ts`(node 환경 정적 스캔):

1. 화면 소스(`src/**/*.ts·tsx`, 시험 파일 제외)에 금지 문구 0건 — `출력 작업`·`XLSX 출력`·`관리자가 설정`.
2. XLSX 산출 동작 라벨이 '내보내기'로 통일(`XLSX 내보내기`·`내보내기 상태`·`내보내기 다운로드`, 장부 `내보내기 작업`).
3. 라벨 사전이 표준 용어 사용(`item=항목`, `category=분류`, `card_kind=카드 구분`, `income_kind=수입 구분`, `kind=구분`).

## 경계

- 이 용어집은 React 프런트(`frontend/`) 화면 문구에 적용한다. 레거시 Python 화면(`webapp/ledger_design.py` 등)의 과거 혼용은 수락 정본이 지적한 원래 결함이며, React 이식 화면은 위 표준을 따른다.
- 고객 원문·금액은 이 문서·시험에 넣지 않는다(합성 라벨만).
