# 보험 후보와 여행 검토 UX

2026-10-31 사용자 요청: 보험 명단 로딩 상태를 개선하고, 후보 건수에서 실제 비교 작업으로 이어지며, 여행 검토에서 다음 행동을 알 수 있게 한다. 기존 CORE-04/08의 화면 개선이며 별도 회계 완료 상태를 만들지 않는다.

- 명단 요청 중에는 수입 행과 패널에 대조 진행 상태를 표시한다. 요청은 25초 후 중단하며 실패 시 같은 위치에서 재시도한다. 한 번에 요청 하나만 실행한다.
- 수입 행의 보험 후보 및 글자 일치 결과는 버튼이다. 선택한 수입의 이름·날짜·금액과 후보의 가림 이름·보험 기간·일치 근거를 모달에서 비교한다. 전체 보험 명단을 이 여행 수입과 비교하는 기존 화면으로 이어진다. Escape와 닫기 버튼으로 돌아가면 원래 버튼에 포커스를 복원한다.
- 여행 검토는 기본으로 펼쳐진 여행별 작업 3개(보험 후보 비교, 지출 대조, 수입·마감 확인)를 먼저 표시한다. 전체 여행 자료 도구 4개는 별도로 접고 범위를 설명한다. 모든 작업에 기존 아이콘과 키보드 포커스를 유지한다.
- 가림 글자 대조는 참가자 확정이나 가입·입금 완료의 증거를 대신하지 않는다. 명시적 수동 연결과 Google 세대 일치 보호가 우선한다. 기존 참가자 연결 버튼은 로딩과 실패·재시도 과정에서도 보존한다.
- Google·금융·명단 원본 쓰기, 스키마·일정 변경과 카드 수집은 포함하지 않는다.

검증은 합성 자료의 로딩/실패/재시도/후보 비교/닫기/모바일/수동 연결 경계 및 실제 로그인 화면의 행별 대조와 비교 창을 대상으로 한다. 실제 참가자 확정 자료와 물리 기기 검수는 기존 외부 조건을 유지한다.
