반드시:
- 이 workspace와 네가 소유한 Paseo IAB 세션/브라우저/탭 하나만 사용한다. 다른 agent의 browserId/tab을 사용하지 말고 새 agent나 새 세션을 만들지 말라.
- Paseo IAB만 사용한다. Edge, UIA, CDP, 일반 브라우저로 폴백하지 말라.
- Agoda Upcoming과 Completed 목록을 현재 화면에서 다시 열고, 현재 실제로 렌더링된 호텔 예약 카드만 열거한다. 과거 artifact/DB의 예약 ID는 탐색 대상으로 사용하지 말라.
- 상세 페이지는 절대 열지 말라. 예약 카드 내부의 data-element-name="blp-booking-item-button-edit" control이 존재하는지와 그 카드의 예약 ID만 수집하라. control 순번, 전체 DOM 버튼 index, 위치 range, 일반 텍스트 partial match는 금지한다.
- 고객센터/도움말/지원 control은 존재 여부만 기록하고 절대 클릭하지 말라. chat dialog root와 입력 placeholder가 실제로 보인다고 해서도 닫거나 상호작용하지 말라.
- 목록/페이지 로딩은 같은 세션에서 최대 5회 bounded retry만 허용하고, PASEO_BROWSER_UNAVAILABLE/timeout이면 구체적 failure code와 RETRY_EXHAUSTED를 남겨 종료하라.
- 파일, DB, artifact에는 쓰지 말라. 출력은 네 최종 응답 JSON 하나뿐이다.
