## 사용자 결정과 변경

날짜 아래의 `장부에 있음 · 복사 제외`, `Google 장부 대조 후보`는 사용자가 수행할 행동을 설명하지 않으면서 행을 늘렸다. 날짜 칸에는 날짜만 두고, 모바일 거래 목록에서도 긴 대조 문구를 제거한다. 별도 상태 열이나 배지를 추가하지 않는다.

기존 후보의 굵은 강조와 낭독 가능한 설명은 보존한다. PC 설명 노드는 날짜 셀에서 거래처 셀로 이동하며 레이아웃을 차지하지 않는다. 사용자가 근거를 찾을 때는 기존 거래 상세의 접힌 `Google 장부 대조 근거`에서 전체 복사 상태와 후보 근거를 읽는다. 상세는 owner의 동일 여행·선택된 정상 스냅샷만 읽고, 후보와 동일 거래 확정을 구분한다. 정상 스냅샷이 없으면 근거를 만들지 않는다.

복사 가능 건수·금액·제외 요약과 실제 복사 제외 판정은 기존 경로를 유지한다. 금융 분류·여행 배정·원본·DB·Google 쓰기 및 사용자 작업 생성은 없다. [Google 장부 명세](google-ledger.md)의 기존 후보 강조 계약 중 행 아래 가시적인 근거 문구는 이번 결정으로 대체하며 후보 계산·권한·강조·복사 보호는 유지한다.
