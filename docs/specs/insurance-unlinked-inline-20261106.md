# 미연결 수입 행 아래 연결 메뉴

## 최신 사용자 교정: 참가자 버튼으로 즉시 선택 (2026-11-06)

현재 요청은 수입 행 아래에 반복되는 이름·날짜·금액 설명과 별도 `수입에 연결` 버튼을 없애고, 참가자 이름 버튼을 선택하면 해당 수입에 바로 연결하는 것이다. 아래 PR #696의 완료 기록은 종전 버전의 이력이며 이번 교정의 배포 완료를 의미하지 않는다.

- 원수입은 hidden income_ref로 고정하고, 원행의 이름·날짜·금액 반복 설명과 드롭다운·별도 연결 버튼을 참가자 이름 버튼으로 대체한다. 여러 후보 때문에 자동 연결하지 못한 기존 사유와 저장 진행/실패 안내는 유지한다. 공용 참가자 관리 폼과 다른 수입으로 이동하지 않는다.
- 버튼 선택은 기존 owner/CSRF/trip/input_fingerprint API를 사용한다. 중복 제출을 막고 저장 중 버튼을 비활성화하며 오류 시 행 안에 재시도 방법을 안내하고 다시 활성화한다. 드래그·연결 해제의 기존 확인 절차는 유지한다.
- 모바일 줄바꿈, 키보드 Enter 선택·Escape 닫기/포커스 복귀, stale409 무저장, 기존 환불·수동 연결·원본·Google 보호를 검증한다. 운영에서 실제 고객 연결을 시험하지 않는다.
- 누락 원인: 행 아래로 공용 폼을 복제하면서 `.participant-selected-income`의 원행 정보와 별도 제출 버튼까지 그대로 노출했다. 종전 수락은 위치·원수입 고정·확인/취소·접근성에 집중했고, 원행과의 정보 중복 및 참가자 선택 뒤 불필요한 제출 단계를 검사하지 않았다. 이번 회귀 검사는 행 아래 select/반복 설명/별도 연결 버튼이 없고 참가자 Enter 선택이 한 POST만 실행하는지 확인한다.
