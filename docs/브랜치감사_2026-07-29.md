1. raw/source snapshot  2. curated source evidence  3. derived decision/review state
4. generated projection/report  5. provenance manifest  6. code/test/config.
`N/A-doc`은 운영 문서·정책·README·LOG·handoff이며 6과 구별한다.

않는다. booking/insurance periods는 curated evidence, `ota_event_links`는 derived
decision-source, `ota_group_assignments`는 fail-closed review state,
`manual_special_rows`는 curated input과 decision 혼합, `agoda_direct_browser_evidence`
는 external source extract, classified/output/reconcile/queues는 generated다.
manifest는 hash 일치 시에만 provenance 후보다.
