## 발견·수정

- 카드 전체 내역의 취소 표시/미배정 필터가 연결된 환불 묶음만 인식해, `refunds` 분류 및 취소 확인 보류를 미배정으로 표시했다. 장부 기기록 여부 자체가 조건인 것은 아니다.
- 읽기 투영에 저장된 환불 분류와 동일 원본의 `cancelled` 보류를 포함한다. 유효 여행 귀속·원본이 달라진 보류·이용 확인 보류는 이 추가 조건으로 숨기지 않는다. 목록·상세·집계·페이지 조건을 일치시킨다.
- 취소 정산 탭에서도 과거 `unclassified`에 남은 취소 확인 건을 읽기 전용으로 표시한다. 여행·분류·보류·금액·원본·금융 링크·장부·Google에 쓰지 않는다.
- 취소 정산 표시는 원결제 검증·기장·환급 완료와 다르다. 이전 사용자 결정과 원문을 수정하지 않고 이력에서 표시 근거를 읽는다.
