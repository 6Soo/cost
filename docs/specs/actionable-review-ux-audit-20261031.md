# 상태만 표시되는 UX 조사·교정

실행 범위는 사용자 요청 “검토 필요로만 되어있고 내가 아무것도 할 수 없는 UX 수정, 모든 웹페이지의 같은 문제 조사·수정”이다. 과거 개발 큐는 포함하지 않는다.

목적은 상태 옆에서 대상 거래의 수정·근거 확인 또는 실패한 조회의 재시도를 시작할 수 있게 하는 것이다. 기존 금융 판단, 원본, 수동 결정, 권한·CSRF·revision 보호와 Google 최종 장부 쓰기 금지를 유지한다. 종료 조건은 아래 발견 항목의 구현·표적 검증·검수·정상 병합·고정 SHA 배포다.

## 조사 결과

운영 웹앱의 라우터와 연결된 렌더러·클라이언트를 조사했다. 아래는 소스 조사이며 모든 운영 실자료 상태를 브라우저로 재현했다는 뜻은 아니다.

| 화면 | 상태와 다음 행동 | 처리 |
| --- | --- | --- |
| 카드 전체 내역 `/cards/all` | 검토 배지가 단순 텍스트이고 펼침은 원본 조회뿐 | 배지를 `분류 검토` 링크로 전환. batch·transaction을 전달해 해당 거래 편집 폼을 연다. 상세에도 수정 링크, 미배정에는 검토 링크를 제공한다. 중복은 수정 대신 원본 미리보기로 안내한다. |
| 카드 원본 상세·이전 장부 원본 URL | 원본만 있는 행에는 수정 동선 없음 | 공통 상세 렌더러에 같은 거래 수정·중복 근거 링크를 제공한다. |
| 카드 검토 `/import`, `/cards`, 지출 정리 | 여행·항목 폼, 보류 사유·해제, 원본 문제·취소 근거, 분류 저장·조회 | 기존 동작 재사용. 이번 작업은 금융 처리 규칙을 변경하지 않는다. |
| OTA 목록·검토 | 그룹 구성원 조회 실패 시 컨테이너를 지워 재시도 버튼까지 제거 | 오류를 별도 alert에 표시하고 기존 버튼·클릭 핸들러를 유지한다. 같은 버튼으로 재시도 후 개별 사건을 연다. |
| 여행별 항공권 | 목록·상세 오류에 문구만 표시 | 접은 뒤 다시 펼치지 않아도 같은 요청을 재시도하는 버튼을 제공한다. 세대 충돌은 목록을 초기화한 뒤 재조회한다. |
| 항공권 참가자 연결 | 후보 없음에서 명단을 확인하라고만 안내 | 예약 명단·여행 연결 화면으로 바로 이동하는 링크를 제공한다. 후보/취소/충돌 보호는 유지한다. |
| 참가자·수입 대조 | 명단 미연결·Google 자료 없음·대조 차단의 상태만 표시 | 여행 수입·명단, 장부 연결 설정, 명단 미연결 시 예약 명단·여행 연결로 가는 링크를 제공한다. |
| 여행 관리 `/trips` | 수정할 수 없는 내부 권위 상태를 `검토 필요`로 표시 | 일정 근거 확인 여부로 표현하고 해당 여행 자료·원본 장부 연결 화면으로 안내한다. 근거를 임의로 확인 완료 처리하지 않는다. |
| 장부 `/board`, `/row`, 행 편집·수입 배분 | 행 편집·규칙 대화·배분 수정·이력/되돌리기 | 기존 대상별 동작 확인. 원본 전용 카드의 개선은 공통 상세에 반영된다. |
| 실제 자료 검토 `/review` | 후보 선택·검토 메모·결정 저장·원본 보기·재조회 | 기존 동작 확인. 활성 카드 모드의 연결 경로도 보존한다. |
| 예약 연결 `/reserve-links` | 여행 선택·연결 저장·명단 적용·다시 불러오기 | 기존 동작 확인. 비활성 저장/적용은 선택·변경·미리보기 조건에 따라 활성화된다. |
| 영수증 `/receipts` | 사진 원본·날짜/통화/금액/결제수단 수정·분류 | 기존 동작 확인. 검증 보류를 해제하는 가짜 완료 버튼을 만들지 않는다. |
| Google 장부·연결 설정·상세 | 원본 링크·정본 선택·매핑 수정·실패 후 재확인 | 기존 동작 확인. 최종 Google 장부 쓰기는 추가하지 않는다. |
| 출력 `/export` | 담당자 확인·여행 선택·생성·다운로드 | 기존 동작과 담당자 확인 연결을 검사한다. |
| 규칙·계정·제공자 설정·로그인 | 규칙 수정·응답, 권한 결정, 모델 재조회, 로그인 재시작 | 기존 폼/권한별 동작 확인. 접근 제한을 우회하지 않는다. |
| 합성 수입/지출 입력·가져오기 | 입력 저장·가져오기·실패 안내·분류대기 링크 | 기존 폼 동작 확인. 운영 모드의 읽기 전용 수입 계약은 유지한다. |

## 검증과 경계

새 동작 검사는 임시 SQLite와 합성 HTTP/브라우저만 사용한다. 월·연도검색·날짜없는 거래의 batch/거래 링크, 원본 조회 전후 dump 동일성, 카드 목록에서 실제 편집 폼까지 이동, OTA 실패→재시도→개별 사건 버튼, 항공권 목록/상세의 각각 실패→재시도, 참가자 자료 누락의 목적지를 확인한다.

기존 카드 모바일·조회·권한, OTA 세대/페이지, 항공권·참가자·출력 담당자 검사를 인접 검증으로 사용한다. 고객 금융/여행/분류/환불·Google 쓰기와 원본 적재·마이그레이션은 실행 범위가 아니다. 실제 검사 결과·배포 SHA는 현재 상태와 운영 기록에 남긴다.
