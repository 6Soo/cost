# Python 기능 단위 리팩토링 · 2026-11-01

현재 승인: 준비기간을 숙박 외 모든 비용에 확장하고, 전체 Python 소스를 조사하여 경량화·중복 제거·복잡성·성능을 개선한다. Rust는 실측 이득과 배포·언어 경계 비용을 함께 평가한다. 과거 리팩토링 목록은 참고 자료이며 자동 실행 큐가 아니다.

## 실행 계약

- 준비기간: 실제 이용기간/수동 배정이 우선한다. 해당 국내·해외 구분의 여행 안에 있으면 기존 기간 배정을 유지하고, 여행 사이 빈 기간의 모든 비용은 가장 가까운 다음 검증 여행의 준비 비용 후보로 배정한다. 여행을 만들거나 종료일을 바꾸지 않는다. 근거에 준비기간 추론을 남긴다. 기존 3820 국내 잔여 분기 규칙·사용자 예외와 환불/원본/중복 보호를 유지한다.
- 전체 추적 Python을 AST로 조사한다. 코드량, 함수 길이/분기, 정확 구조 중복, 내부 import 의존을 같은 명령으로 전후 비교한다. 문자열 템플릿을 옮긴 것만으로 코드 축소를 주장하지 않는다.
- 기능군별로 소유권을 나누고 기존 import/API·권한·원자 저장·금융 링크를 보존한다. 각 군의 관련 검사와 공통 보호 경계를 통합 확인한다.
- 운영 원본·Google 최종 장부 쓰기 금지. 분류 교정은 기존 승인과 위험별 복구 게이트 내에서만 실행한다. 코드 배포와 실제 데이터 변경의 근거를 구분한다.
