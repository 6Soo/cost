# 코드와 규칙이 다른 곳

> [판정 규칙집](../DECISION_POLICY.md)의 규칙과 현재 코드가 다르게 동작하는 지점이다. 규칙이 정본이고 코드가 고칠 대상이다.
> 통합 명세 로드맵의 M2에서 P2 연결과 함께 정리한다. 별도 재현 근거를 적은 항목 외에는 코드를 읽어 찾은 것이며 실행해 재현한 것은 아니다.
