# 미연결 수입 행 아래 연결 메뉴

사용자 요청 범위: 여행 수입표의 `미연결`을 누르면 해당 원행 바로 다음에 전체 열을 병합한 연결 메뉴를 표시한다. 다른 보험 영역으로 이동하지 않고 참가자를 선택한다. 기존 [인라인 비교 결정](insurance-inline-comparison-20261105.md)을 연결 폼에도 적용한다.

| 요구사항 | 구현·검증 |
| --- | --- |
| 행 아래 연결 메뉴 | 원행 직후 펼침, 원수입 고정, 행별 독립 열기·닫기 |
| 키보드·모바일 | 선택창 포커스, Escape 닫기·트리거 복귀, 1440/390/320px 실제 ego 합성 화면 |
| 저장 보호 | 기존 확인·취소, CSRF/trip/input_fingerprint, 변경 자료 409를 행 안에서 안내 |
| 자동 연결 원인 | 확정 명단의 동일 가림 이름 복수 후보는 유일성을 충족하지 못함. 후보 수와 자동 연결 불가 사유를 표시하고 단일 텍스트 대조 결과로 덮어쓰지 않음 |
| 보호 범위 | 이름 양방향 유일성·수동 결정·환불·원본·Google 유지. 임의 인물 병합·운영 연결 쓰기 없음 |

합성 인물만 테스트·Git 문서에 사용한다. 운영 읽기 진단의 개인정보는 비공개 로컬 증거에만 보존한다. 동일 가림 이름 둘 중 하나를 이름만으로 자동 선택하는 규칙은 추가하지 않는다.
