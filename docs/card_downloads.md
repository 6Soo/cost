# 국민 기업카드 자료 수집과 사용 기준

2026-10-08 기준으로 아래 원본 수집 결과와 웹 가져오기 상태를 구분한다. 국민 원본 3개는 보존돼 있고 국내·해외 매입의 행별 검사는 완료했다. 현재 웹 업로드는 CSV·XLSX를 지원하며 바이너리 XLS는 직접 지원하지 않는다. 하나·기업의 기존 승인 파일과 국민의 변환 자료로 구성한 운영 파일 5개는 이미 가져온 상태다. 현재 운영 수치는 [운영 문서](operations.md)를 따른다.

국민 국내 매입 원본에서 760,200원 취소 전표가 기존 항공권 원결제와 정확히 연결됨을 확인했다. 기존 미확인 기록을 환불 원문 부재로 계속 해석하지 않는다. 새 원본의 운영 가져오기와 승인·매입 중복 연결 검증은 아직 남아 있다. 원본 검사 완료를 일괄 장부 반영 완료로 표시하지 않는다.


장부의 비용 금액과 취소 전표는 **국내 매입 내역과 해외 매입 내역을 각각 받아서** 확인한다. 승인 내역은 최근 사용, 승인 취소, 승인번호와 매입 전 거래를 확인하는 보조 자료로 보존한다. 세 파일을 그대로 합쳐 비용으로 기록하지 않는다.

## 자료별 역할

| 자료 | 필요 여부 | 확인할 내용 | 조회 기준 |
| --- | --- | --- | --- |
| 국내 매입 내역 | 필수 | 정당전표, 취소전표, 원화 금액, 매입일, 원승인번호 | 매입일 |
| 해외 매입 내역 | 필수 | 현지 금액, 미화 환산액, 결제원금, 수수료, 총 결제금액, 취소매출 | 매입일 |
| 승인 내역 | 보조 | 최근 승인, 승인 취소, 승인번호, 승인시간, 매입 전 사용 | 승인일 |

승인 화면은 매입 취소를 국내 매입 화면에서 조회하라고 안내한다. 국내 매입 화면도 승인 취소는 승인 화면에서 조회하라고 안내한다. **승인 취소와 매입 취소는 서로 다른 상태다.** 승인 취소만 읽어서 정산된 환불이 모두 반영됐다고 판단하지 않는다. 매입되지 않은 승인 취소를 새 환불 비용으로 기록하지 않는다.

## 다운로드 경로와 조건

2026-10-05에 실제 로그인된 회사 세션에서 확인한 경로다. 탭과 계정, 회사명, 로그인 여부는 실행할 때마다 다시 확인한다.

- 승인: `https://biz.kbcard.com/CXERCMLSD0001.cms`.
- 국내 매입: `https://biz.kbcard.com/CXERCMLSD0002.cms`.
- 해외 매입: `https://biz.kbcard.com/CXERCMLS0008.cms`. 전체메뉴 → My Biz → 이용내역 → 해외매입내역으로 이동한다.
- 회사 전체를 받으려면 조회구분은 `사업자`로 둔다. 승인 매출구분은 `전체`, 국내 매입 전표 필터는 `전체`로 둔다.
- 국내 매입은 최근 24개월 범위에서 전날까지 조회할 수 있다. 해외 매입은 최근 24개월 이내, 승인은 최근 12개월 이내 조회가 가능하다. 최종 허용 종료일은 현재 화면에서 확인한다.
- `XLS 파일저장` → 새 화면의 `엑셀파일저장` 순으로 실행한다. 다운로드 이벤트와 실제 파일을 모두 확인한다. 승인번호를 얻겠다고 마스킹 해제나 재서명을 실행하지 않는다.
- 파일은 `kb-domestic-acquired-시작일-종료일.xls`, `kb-overseas-acquired-시작일-종료일.xls`, `kb-approval-시작일-종료일.xls`로 구분한다. 원래 다운로드 이름은 실행 기록에 남긴다.

같은 숫자의 기간을 입력해도 승인과 매입의 포함 거래는 다르다. 이번 국내 매입 파일에는 2025년 승인 거래의 2026년 매입·취소도 들어 있다. 조회 기간 밖의 원승인일이라는 이유로 매입 행을 버리지 않는다. 기간 갱신은 매입일을 기준으로 겹치는 구간을 다시 받아 검증하며, 지연 매입·취소 누락이 의심되면 더 넓은 매입 기간을 재조회한다.

## 금액과 거래 연결 규칙

1. 국내 금액은 원본 `승인금액`과 `상태`를 함께 읽는다. `승인구분`은 국내외 구분이며 취소 상태가 아니다. 취소 전표의 `승인번호`는 `취소번호(원승인번호)` 형식이므로 두 번호를 별도로 보존한다.
2. 해외 비용의 청구 원화는 `총결제금액`을 사용한다. `결제원금`과 `수수료`를 별도로 보존하고 `결제원금 + 수수료 = 총결제금액`을 검사한다. 총 결제금액에 수수료를 다시 더하지 않는다. 카드사의 원화 금액이 있는데 자체 환율로 재계산하지 않는다.
3. 해외 취소는 `결제방법=취소매출`로 식별한다. 이번 취소 원본 70행의 금액은 모두 양수다. 원본은 그대로 두고 정규화한 취소 효과만 음수로 표현한다. 화면의 취소금액 요약이 0원이어도 상세 취소 행을 누락하지 않는다.
4. 해외 원본에는 승인번호가 없다. 카드·승인일·가맹점·미화 환산액·거래 종류가 유일하게 일치하는 승인 행은 연결 후보가 될 수 있지만, 금액이나 날짜가 다르거나 후보가 여럿이면 임의로 번호를 붙이지 않는다. 현지 통화 금액과 미화 승인액을 직접 비교하지 않는다.
5. 해외 파일에는 모든 열의 값이 같은 복수 거래도 있다. 값이 같다고 삭제하거나 합치지 않는다. 동일 원본의 재수집 방지는 파일 해시와 원본 행 위치로 처리하고, 파일 간 연결은 실제 복수 거래의 개수와 연결 근거를 보존해야 한다. 승인번호 없는 해외 행의 확정 연결은 별도 처리 대상이다.
6. 승인과 매입에 있는 같은 결제는 출처가 둘인 한 거래다. 매입된 거래의 비용 금액은 매입 원본을 사용하며 승인액을 추가 전기하지 않는다. 승인 취소와 취소매입도 각각의 상태를 보존하고 환불 효과를 두 번 기록하지 않는다.
7. `현금서비스`, `리버설-일시불매출` 같은 다른 거래 종류는 원문과 금액을 보존하고 별도 검토한다. 모두 일반 여행 비용이나 환불로 자동 처리하지 않는다. 취소 전표가 있다는 사실과 은행 계좌에 현금 환급이 완료됐다는 사실도 구분한다.

## 실제 검증 결과

2026-10-05 수동 로그인된 세션에서 조회 기간 2026-04-01~2026-10-04의 원본 세 개를 다운로드했다. 이번 결과는 무인 로그인 성공 증거가 아니다.

| 원본 | 전체 행 | 정상 또는 기타 매출 | 취소 행 |
| --- | ---: | ---: | ---: |
| 승인 | 2,124 | 1,840 | 284 |
| 국내 매입 | 1,016 | 861 | 155 |
| 해외 매입 | 764 | 694 | 70 |

- 국내 취소매입 금액은 42,909,834원이다. 155행 모두 원승인번호가 있고, 같은 카드와 원승인번호로 국내 승인 취소 원본에 일치하는 행은 0행이다. 해외 승인번호와 국내 원승인번호를 섞어서 비교하지 않는다. 승인 취소가 매입 취소를 대신하지 못한다는 원본 근거다. 조회 축과 거래번호 의미가 다르므로 단순 행수 차이를 누락 건수라고 해석하지 않는다.
- 해외 취소매입의 총 결제금액 합계는 12,130,780원이다. 764행 모두 원금·수수료 합산 검사를 통과했다.
- 해외의 694개 비취소 행에는 일시불매출 691행, 현금서비스 1행, 리버설 2행이 포함된다. 해외 원본의 승인번호는 0개이며 값이 같은 복수 행은 보존했다.
- 해외 승인 정상 합계는 화면에서 83,259.99달러, 다운로드 원본 집계에서 83,263.50달러였다. 3.51달러 차이의 원인은 확인하지 못했다. 화면 합계만으로 원본 무결성을 주장하지 않으며 승인액을 청구 원화 대신 사용하지 않는다.

원본, 파일 해시, 행별 구조 집계와 비교 결과는 `.local-archive/card-downloads/20261005-kb-source-review`에 보존했다. 운영 DB와 장부는 변경하지 않았다. 현행 웹 업로드는 이 바이너리 XLS 원본을 직접 지원하지 않으므로, 원본 검증 완료를 웹 반영 완료라고 보고하지 않는다.

## 반복 실행

카드 다운로드 스킬 `cost-card-download`와 그 `scripts/download.ps1`에 같은 자료 선택 기준을 반영했다. 이미 로그인돼 있으면 해당 세션을 사용한다. 수집 완료 판정에는 국내·해외 매입 각각의 다운로드 또는 실제 0건 근거가 필요하다.

원본 비교는 다음 명령으로 재실행할 수 있다. 실제 파일 경로와 조회 기간을 바꾼다.

```powershell
python tools/inspect_kb_exports.py --approval .local-archive/card-downloads/20261005-kb-source-review/kb-approval-20260401-20261004.xls --domestic .local-archive/card-downloads/20261005-kb-source-review/kb-domestic-acquired-20260401-20261004.xls --overseas .local-archive/card-downloads/20261005-kb-source-review/kb-overseas-acquired-20260401-20261004.xls --from 2026-04-01 --to 2026-10-04 --output .local-archive/card-downloads/20261005-kb-source-review/source-comparison.json
```

분석 도구는 XLS 읽기용 `xlrd`를 사용한다. 현재 작업 환경에서는 이미 보존된 `.local-archive/card-downloads/parser-libs`를 사용할 수 있다. 원본과 운영 DB를 수정하지 않으며 집계 보고서만 쓴다. 새 다운로드를 기존 원본 위에 저장하지 않는다.
