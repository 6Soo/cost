# COST 지출 행 인라인 편집·다중 선택 UX 상세 명세 (2026-11-02)

상태: **PARTIAL — 구현·합성 브라우저 수락·운영 배포 완료, 운영 편집 흐름 수락 미확인**. 기본 구현 PR #549와 후속 PR #555는 2026-11-03 순차 배포 `ac2eed1635bd8b807abdee2e6dbcd382ef969225`에 포함됐다([운영 기록](../operations.md#2026-11-03-게이트웨이보험-순차-고정-sha-배포)). 이 SHA는 당시 배포 근거이며 현재 운영 SHA를 뜻하지 않는다. 후속 수정은 변경하지 않은 여행의 수동 고정 방지와 모바일 하단 여행 선택기 폭 개선이다. 기존 [전체 UX 감사](full-ux-audit-20261101.md)와 [금융/카드 보호 계약](finance.md)을 보완한다.

합성 Ego TaskSpace 78에서 단일 항목 저장→다중 선택→여행 일괄 저장과 항목 보존, 1440px/390px/320px·라이트/다크, Enter/Space/Shift/Escape, 미저장 내용 보존, 수동 보호 실패 및 두 탭의 revision 충돌 시 선택·대상 유지, 거래처 열 읽기와 가로 넘침 없음을 확인했다. 실기기·실제 금융 자료 쓰기·Google 쓰기는 수행하지 않았다. 과거 게이트웨이 설치 차단은 후속 순차 배포로 해소됐다. 남은 수락은 인증 운영 PC·모바일에서 인라인 열기·다중 선택 전환·하단 바·입력 보존의 읽기 동선을 확인하는 것이다. 실제 고객 거래 저장은 별도 승인 범위를 유지하며 합성 저장 수락을 운영 저장 완료로 취급하지 않는다. 최신 호스트 상태는 [현재 상태](../session_handoff.md)를 따른다.

## 목표와 화면 모델
- 여행 지출 목록에서 거래를 누를 때 우측 사이드 패널이 아닌 **선택 행 바로 다음 줄**에 전체 너비의 편집 영역을 삽입해 다음 거래를 아래로 민다. 목록 문맥과 필터/스크롤 위치를 유지한다. 데스크톱과 모바일 동일한 상호작용 원칙을 적용한다.
- **기본 목록에 체크박스나 상시 '여러 건 선택' 버튼을 두지 않는다.** 단일 편집 영역 안의 **'다른 거래도 함께 변경'**으로만 다중 모드를 시작한다. 기본 화면은 기존 밀도와 열 너비를 유지한다.
- 새 독립 메뉴, 새 페이지, 별도 일괄 작업 대시보드는 만들지 않는다. 기존 거래 행/여행 선택기/서버 변경 경로와 공통 CSS를 우선 재사용한다.

## 상태별 정확한 동작
1. **기본/열림:** 거래 행 클릭·Enter → 해당 행 바로 아래 인라인 편집 행 열기. 현재 여행, 변경할 여행 검색 선택기, 기존 비용 항목, 저장/취소, '다른 거래도 함께 변경' 표시. 동일 행 재클릭/Escape/닫기 → 접기. 다른 행 클릭 시 기존 편집을 접고 새 행에서 열되, 저장 전 변경사항이 있으면 안전한 이탈 확인 또는 변경 상태 보존. 우측 패널은 동일 작업에서 사용하지 않는다.
2. **단일 저장:** 변경할 여행을 명시적으로 선택하고 기존 항목은 기본 유지. 항목 수정은 사용자가 해당 필드를 직접 변경할 때만 적용. 현재 거래의 revision·권한·분류/금융 보호 검증을 거쳐 저장. 성공하면 해당 행 정보와 여행별 목록/합계 갱신, 편집부 접기 또는 성공 표시, 현재 필터/스크롤 문맥 보존. 실패하면 입력을 보존하고 원인을 인라인 표시.
3. **다중 전환:** 열려 있는 단일 편집의 '다른 거래도 함께 변경' 클릭 → 최초 거래를 선택한 채 다중 선택 모드로 전환. 앞서 고른 대상 여행은 유지. 인라인 편집창은 닫고 **화면 하단 고정 작업 바**로 대상 여행 선택·선택 건수·선택 총금액·'N건 변경'·선택 종료를 이동.
4. **다중 선택:** 선택 모드에서 거래 행 전체를 눌러 선택/해제. 체크박스는 쓰지 않는다. 선택 행은 **은은한 파란 배경 + 왼쪽 3px 파란 강조선**으로 구별하고, hover와 선택 상태를 별도 표현한다. 라이트 모드 예시 선택 #EFF6FF, 강조 #60A5FA, 선택 hover #DBEAFE; 다크 모드는 대비가 확보되는 남색 계열 토큰으로 처리한다. 색상만으로 의미를 전달하지 않도록 선택 건수·접근성 상태와 포커스 표시를 제공한다. Shift+클릭으로 연속 범위 선택, 키보드 Space/Enter로 토글. 행 내 링크/버튼은 의도한 기능이 실행되어야 하며 선택 이벤트가 중복 발화하지 않는다.
5. **목록 경계:** 전체 선택을 제공한다면 현재 페이지/필터에 나타난 거래만 대상으로 하고 그 범위를 명확히 표시한다. 숨겨진 페이지, 다른 여행, 필터 밖 거래를 암묵적으로 포함하지 않는다. 검색·정렬·페이지 이동 시 선택을 보존할지 해제할지 일관된 정책을 적용하고, 숨은 선택 건수가 포함되면 명시적으로 보여준다. 동일 날짜·가맹점·금액의 별도 실거래도 고유 거래 ID 기준으로 각각 선택하며 DOM 행 위치나 표시 문자열을 ID로 사용하지 않는다.
6. **다중 편집 바:** 스크롤 중에도 볼 수 있는 하단 고정/안전영역 배치. '선택 N건 · 합계 X원', 대상 여행 검색/선택, 'N건 변경', '단일 편집으로 돌아가기/선택 종료' 제공. 모바일에서 콘텐츠를 덮지 않도록 하단 여백 확보. 선택 0건 또는 변경할 여행 미선택 시 저장 비활성화. 선택이 끝나면 기본 목록으로 복귀하고 선택 표시 해제.
7. **변경 범위:** 일괄 작업의 기본은 **여행 배정만 변경**. 비용 항목/메모/금액/원본/수동 결정/예약·환불 링크는 변경하지 않는다. 비용 항목까지 일괄 변경하는 기능은 필요하면 별도 명시적 사용자 동작으로 확장하되 이번 범위에서 자동 변경하지 않는다.
8. **저장 원자성:** 일괄 저장은 서버에서 선택된 거래 전체의 식별자, 현 revision, 권한, 실제 유효 여행, 수동 교정·보류·중복·환불·금융 연결 보호를 검증한 뒤 **전부 성공 또는 전부 취소**로 처리한다. 하나라도 막히면 어느 거래가 왜 차단됐는지 표시하고 다른 거래도 쓰지 않는다. 확인 전 미리보기에는 변경 건수/대상 여행을 표시. 멱등 요청키를 지원하고 재전송으로 이중 적용하지 않는다. 기존 단일 저장 API를 반복 호출해 부분 성공을 남기는 구현은 피한다.
9. **결과와 접근성:** 성공 후 갱신된 행·합계와 이동한 거래 수를 표시하며 필터로 목록에서 빠진 행은 조용히 사라진 이유를 설명한다. 실패 시 선택과 여행 선택값 유지. 펼친 영역은 원행과 연결된 행/영역 관계를 스크린리더에 알리고, 다중 모드 전환/선택 상태/오류를 aria-expanded, aria-selected 또는 적절한 의미론 및 live region으로 전달한다. 포커스는 인라인 편집 → 작업 바 → 목록으로 논리적으로 이동한다. 좁은 화면 320/390px, 데스크톱, 키보드, 밝음/어두움 테마 모두 확인한다.

## 데이터·권한 불변조건
- 기존 owner/viewer 권한, CSRF, revision/원자 저장, 거래/여행의 권위 출처, 수동 보호, 중복·취소/환불 연결을 유지한다.
- 원본 바이트·원행·금액·승인번호 및 기존 장부/금융 링크를 변경하지 않는다. Google Sheets는 읽기 전용이며 자동 기장/쓰기 0. 화면의 선택은 여행 귀속/사용자 결정을 몰래 갱신하지 않는다.
- 인라인 단일 편집과 다중 편집의 검증 규칙을 공유하되 기존 비즈니스 정책을 단순화한다는 이유로 우회하지 않는다.

## 완료·검증 기준
- 기본 목록에 체크박스/상시 다중 선택 버튼 없음. 행 클릭 시 우측 패널 대신 해당 행 **바로 아래** 편집 영역이 열리고 다음 거래가 밀려남. 같은 행 재클릭·다른 행 클릭·Escape 및 미저장 편집 동작 확인.
- 편집 안에서 다중 모드로 전환 가능, 최초 거래 자동 선택 및 기존 대상 여행 유지. 여러 행 선택/해제·Shift 선택·스크린리더/키보드 지원. 선택된 행은 파란 배경+왼쪽 강조선, 비선택 행은 기존 스타일.
- 하단 작업 바에서 여행 일괄 변경 후 항목은 그대로 유지, 합계와 행 목록 갱신. 선택 0건/미선택 여행 저장 차단. 스크롤/모바일 가림/가로 넘침 없음.
- 3건 중 1건이 권한/환불/수동 보호로 실패하는 경우 **3건 모두 미변경**; 전체 통과 시 **3건 모두 변경**. 중복 제출·동일 금액 별도 거래·필터 변경·동시 revision 충돌 회귀 확인.
- 기존 카드 업로드/지출 복사/Google 대조/수동 결정의 회귀 검사 및 인증 브라우저(PC·모바일) 실제 업무 흐름을 검증. 결과에서 구현/검증/배포 상태를 구분해 보고한다.
