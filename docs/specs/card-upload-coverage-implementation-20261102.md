## 통합 시 확인할 경계

- 실제 업로드는 `webapp/card_flow.py`의 `/api/imports` 경로다. 합성 전용 `webapp/card_import.py`에만 구현하고 완료하지 않는다.
- 조회 GET에서 DDL이나 확인 기록을 쓰지 않는다. 기존 DB에 신기능 저장 구조가 준비되지 않아도 기존 업로드를 망가뜨리지 않는다.
- 클라이언트가 보낸 카드 ID·메타데이터 출처·완전성 선언만으로 신뢰를 부여하지 않는다. 저장된 원본·업로드 이력과 서버 검증 결과에 연결한다.
- 새 운영 스키마 준비가 필요하면 적용과 복구 게이트를 별도로 기록한다. 이 문서는 운영 DB 변경 권한을 확대하지 않는다.
- 전체 회귀를 관성적으로 반복하지 않고 변경 기능과 보호 경계의 표적 검사를 한 번 수행한다. 실제 명령·결과·SHA는 통합 후 갱신한다.
